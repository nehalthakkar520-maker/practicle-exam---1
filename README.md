# Smart Bookstore Management System

## Project Overview

Smart Bookstore Management System is a Python-based project developed to manage bookstore inventory, sales, and revenue analysis efficiently. The system allows users to add books, update stock, record sales, and generate analytical reports using data visualization techniques.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## Features

### Inventory Management

* Add New Books
* Update Book Quantity
* Delete Books
* Search Books
* View Inventory Report

### Sales Management

* Record Book Sales
* Automatic Revenue Calculation
* Maintain Sales History

### Data Analysis

* Total Revenue Calculation
* Average Revenue Analysis
* Genre-wise Inventory Analysis
* Monthly Revenue Trend Analysis
* Revenue Share by Book
* Correlation Heatmap
